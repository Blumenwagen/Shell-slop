# QML Shellcraft Forge starter

This is the runnable baseline exported by the course's Shell Forge.

1. Install Quickshell 0.3.x and Qt 6 on Linux.
2. Run `quickshell -p .` from this directory.
3. Edit `shell.qml` while Quickshell runs to practice hot reload.

The course adds completed quest work under `practice/` when generating a learner's project bundle.
